## ✨ 功能特性

### 🔐 多账号管理
- 添加、编辑、删除多个 Kiro 账号
- 一键快速切换账号
- 支持 Builder ID 和社交登录（Google/GitHub）方式
- 批量导入/导出账号数据

### 🔄 自动刷新
- Token 过期前自动刷新
- 刷新后自动更新账号用量和订阅信息
- 开启自动切换后，定时检查所有账号余额

### 📁 分组与标签
- 使用分组和标签灵活组织账号
- 批量设置账号的分组/标签

### 🔑 机器码管理
- 修改设备标识符，防止账号关联封禁
- 切换账号时自动切换机器码
- 为每个账号分配唯一绑定的机器码

### 🔄 自动切换账号
- 余额不足时自动切换到可用账号
- 可配置余额阈值和检查间隔

### ⚙️ Kiro IDE 设置同步
- 同步 Kiro IDE 设置（Agent 模式、模型、MCP 服务器等）
- 编辑 MCP 服务器配置
- 管理用户规则（Steering 文件）

### 🌐 多语言支持
- 完整的中英文双语界面
- 自动检测系统语言或手动选择

### 🎨 个性化
- 21 种主题颜色可选
- 深色/浅色模式切换
- 隐私模式隐藏敏感信息

### 🌐 代理支持
- 支持 HTTP/HTTPS/SOCKS5 代理

## 📋 更新日志

### v1.6.8

**Bug 修复:**
- 🐛 **OpenAI 兼容模式响应中出现 "Using tools." 字样**: 修复了在使用 OpenAI 兼容代理时，内部占位字符串 `"Using tools."` 意外出现在 AI 实际响应中的问题。该字符串是代理为满足 Kiro API 对历史消息 `assistantResponseMessage.content` 非空的要求而注入的，但模型会将其视为正常对话内容并在下一轮中回显。现已替换为 `(tool_call)`，这是一个括号式元数据标记，模型能正确将其识别为非对话内容而不予复述。

完整说明见: `docs/CHANGELOG-v1.6.8.md`

### v1.6.7

**Bug 修复:**
- 🐛 **思考阶段 Token 耗尽瘫痪**: 修复了由于 `max_thinking_length` 上限被设为 200,000 导致 AI 在深度思考时完全榨干 8,192 最大输出 Token，最终造成返回流严重截断崩溃的问题。现将上限限制至 4,000 tokens，以安全保留容量用于正常的文件代码及终端打印。

完整说明见: `docs/CHANGELOG-v1.6.7.md`

### v1.6.6

**Bug 修复:**
- 🐛 **工具调用超时崩溃**: 修复了巨大的 IDE Agent 工具流（如超大文件写入）导致错误触发 15 秒首 Token 超时的问题。现在会在解析到第一个有效网络包时立即停止初次等待计时器以防无故中断。
- 🐛 **丢失的流异常**: 解决了内部 `parseEventStream` 工具流解析异常被吞没导致连接无限挂起的问题，让异常能准确冒泡至重试连接池以触发账号平滑自动切换轮换。

完整说明见: `docs/CHANGELOG-v1.6.6.md`

### v1.6.4

**Bug 修复:**
- 🐛 **API 配额耗尽与智能重试机制**: 修复了在遇到通用速率限制 (`429`) 时引发的 API 无限重试循环问题。现在针对服务器瞬时高并发情况，系统使用指数退避算法 (`1s`, `2s`, `4s` 延迟) 智能轮询端点；并在遭遇绝对配额耗尽 (`Monthly limit exceeded`) 时立刻阻断，安全交由 `AccountPool` 无缝进行账号自动切换。

完整说明见: `docs/CHANGELOG-v1.6.4.md`

### v1.6.3

**Bug 修复:**
- 🐛 **多主体 (Multi-Agent) 流稳定性**: 禁用了系统在流结束后启动的 8 秒请求阻断期。这修复了类似 Claude Code 在多主体自动化任务中无法发送后续请求的问题，避免了被误认为"用户手动取消" (HTTP 499 错误)。

完整说明见: `docs/CHANGELOG-v1.6.3.md`

### v1.6.2

- 🐛 **流解析修复**: 修复了由于 Kiro API 提前终止导致的 Thinking 思考块丢失问题。
